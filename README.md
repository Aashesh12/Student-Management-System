# Student Management System
## Project Description
The Student Management System is a Python console application designed to manage student records and academic information.
The system allows users to add, view, search, update and delete student records. It also allows course marks to be stored and calculates student averages, grades and pass/fail status.

Student information is permanently stored in a JSON file.

## Features

1. Add student
2. View all students
3. Search students
4. View student details
5. Update student
6. Delete student
7. Add or update course marks
8. Calculate student average
9. Calculate student grade
10. Display pass/fail status
11. Display class statistics
12. Persistent JSON storage
13. Input validation
14. Exception handling

## Technologies

- Python 3
- JSON
- Python Standard Library

No external packages are required.
